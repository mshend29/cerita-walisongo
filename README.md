# Cerita Walisongo

Repository umbrella untuk pengembangan serial cerita Walisongo berbasis riset, tradisi, dramatization, dan produksi AI.

## Project structure

Setiap wali/cerita mendapat folder proyek sendiri agar canon, research, character, location, prop, visual, dan episode tidak tercampur.

- `Sunan_Kalijogo/` — proyek serial Sunan Kalijaga / Raden Said
- proyek wali lain dapat ditambahkan sebagai folder paralel

## Working principle

**GitHub = source of truth.**

Dokumen kerja harus membedakan:

- **[H] Historis**
- **[T] Tradisi**
- **[L] Legenda**
- **[D] Dramatisasi**

Perubahan canon tidak boleh dilakukan diam-diam. Semua perubahan yang berdampak pada cerita, karakter, continuity, research interpretation, atau visual lock dicatat di Decision Log proyek.
