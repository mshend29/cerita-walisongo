# ASSETS — SUNAN KALIJOGO

Assets are organized by reusable master type.

- `character/` — approved character reference sheets
- `location/` — approved location master and anchor views
- `prop/` — approved recurring prop references
- `episode/` — episode-specific generated assets

Asset filenames should carry stable IDs where possible:

- `C01-RS-P01-...`
- `L01-...`
- `P02-...`
- `EP01-SH03-...`

Generated assets do not override Markdown canon. The Markdown bibles remain the source of truth.
