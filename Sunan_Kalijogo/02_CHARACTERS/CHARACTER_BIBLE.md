# CHARACTER BIBLE — SUNAN KALIJOGO

## Purpose

Master visual and dramatic reference for every recurring character.

## Character record

Every character must define:

- Character ID
- Name / aliases
- Source status
- Narrative function
- Age by phase
- Face identity
- Skin / eyes / brows / nose / lips
- Hair
- Body / height / silhouette
- Distinctive traits
- Personality and default emotional range
- Gesture language
- Voice
- Wardrobe base and phase changes
- Accessories / props
- Master prompt
- Negative prompt
- Continuity rules

## Character lock rule

**MASTER CHARACTER → PHASE → SHOT PROMPT**

Never redesign a character independently for each episode.
