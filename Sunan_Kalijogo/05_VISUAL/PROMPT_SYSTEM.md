# PROMPT SYSTEM — SUNAN KALIJOGO

## Prompt architecture

`[CHARACTER LOCK] + [PHASE LOCK] + [LOCATION LOCK] + [WARDROBE LOCK] + [ACTION] + [CAMERA] + [LIGHTING] + [STYLE LOCK] + [NEGATIVE]`

## Character master

Use one master description for identity. Do not paraphrase it between shots unless a recorded visual change is intended.

## Location master

Use one master environment plus anchor view.

## Shot prompt

A shot prompt should contain one primary action.

Bad:
> Raden Said walks, fights, talks, steals rice, runs away.

Good:
> Raden Said turns toward the warehouse door after hearing a guard’s footsteps.

## Reference image policy

For each important character create a master sheet with:

- front
- 3/4
- profile
- close-up
- full body
- neutral expression
- anger
- fear
- guilt
- compassion
- calm

For each important location create:

- establishing
- gate/entrance
- courtyard
- main functional area
- residential/side area
- road/transition
