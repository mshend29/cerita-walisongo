# LOCATION BIBLE — SUNAN KALIJOGO

## Purpose

Menjaga lingkungan visual tetap berasal dari lokasi master yang sama.

## Location lock principle

Satu lokasi dibuat sebagai **master environment**, lalu memiliki anchor views. Jangan membuat setiap shot sebagai lokasi baru.

Prompt stack:

`[LOCATION MASTER] + [ANCHOR VIEW] + [TIME] + [ACTION] + [CAMERA] + [LIGHTING] + [STYLE]`

## L01 — Tuban / Kompleks Kadipaten

**Episodes:** EP01–04

Required anchor views:

1. Establishing wide
2. Kadipaten gate
3. Courtyard
4. Food warehouse
5. Rakyat area
6. Noble residential area
7. Road leaving settlement

### Environment lock

- late-15th / early-16th-century Java
- grounded Javanese architecture
- wood, earth, tile/thatch as appropriate
- natural vegetation
- earthy materials
- no modern infrastructure

### Continuity rule

All anchor views must look like different camera positions inside the same coherent settlement.
